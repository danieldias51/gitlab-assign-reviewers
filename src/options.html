GitLab Assign Reviewers

Save named groups of teammates, such as backend and frontend. The popup opens on the default group, and you can switch groups there before adding reviewers.

The site root only. This can be gitlab.com or your company's GitLab.

Reviewer groups

Comma, space, or newline separated. A leading @ is optional.

Authentication

In GitLab: Preferences, then Access tokens. Create a token with the api scope. Leave this blank to forget a saved token.
